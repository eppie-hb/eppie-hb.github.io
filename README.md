# eppie-hb.github.io

Personal portfolio, served by GitHub Pages from `main` via
`.github/workflows/static.yml`.

## Important: this repo contains build output, not source

These HTML files were generated by [Pelican](https://getpelican.com/) with the
Hyde theme, but **the Pelican source is not in this repo** — there is no
`pelicanconf.py` and no `content/` directory with the Markdown originals.

That has one consequence worth knowing before you edit anything:

> If you ever re-run Pelican and copy its `output/` over this repo, every
> change made directly to these HTML files will be silently overwritten.

Two ways to resolve that, in order of preference:

1. **Recommended — commit the source.** Add `pelicanconf.py` and `content/*.md`
   back to the repo (or a `src/` branch), move the hand-edits into the Markdown,
   and build in CI so the published HTML is always generated from source. This
   also removes the duplicated `<head>` and sidebar markup currently repeated in
   all six pages.
2. **Or — declare the HTML canonical.** Accept that Pelican is retired for this
   site and edit the HTML directly. If you choose this, delete any local Pelican
   project so a future build can't clobber the site by accident.

Until one of those happens, the six pages each carry their own copy of the
`<head>` and sidebar, so **navigation or metadata changes must be applied to all
six files**.

## Layout

```
index.html            Landing page
pages/                About, career, skills, education, awards
theme/css/poole.css   Base typography (vendor — do not edit)
theme/css/hyde.css    Sidebar layout + colour themes (vendor — do not edit)
theme/css/style.css   Portfolio-specific styles (edit this one)
theme/css/syntax.css  Code highlighting; unused, kept for a future blog
images/               Profile image, favicon
robots.txt            Points crawlers at the sitemap
sitemap.xml           Update when adding or removing a page
```

## Local preview

Asset paths are root-relative, so open the site through a server rather than
`file://`:

```sh
python3 -m http.server 8000
# then visit http://localhost:8000
```

## Analytics

Page views are counted by [GoatCounter](https://www.goatcounter.com/)
(`eppie-hb.goatcounter.com`). The script is inlined in each page's `<head>`.
